# dev-documentation

README 生成、API ドキュメント、コードコメント、変更履歴生成、技術仕様書、ランブック、オンボーディングガイドに対応するドキュメントスキルを提供します。

## スキル (7)

- **readme-generator** — インストール手順、利用例、API 参照、コントリビューションガイドラインを含む包括的な README.md を生成
- **api-documentation** — OpenAPI/Swagger 仕様に沿って、エンドポイント、パラメータ、レスポンス、例を含む API ドキュメントを作成
- **code-comments** — JSDoc、docstring、インラインコメント、ヘッダドキュメントを追加/改善し、保守性を向上
- **changelog-generator** — Keep a Changelog 形式に沿った CHANGELOG.md を生成し、バージョン履歴と主要変更点を記録
- **technical-spec** — アーキテクチャ判断、システム設計、実装詳細を含む技術仕様書を作成
- **runbook** — デプロイ、インシデント対応、監視、運用保守手順を含む運用ランブックを作成
- **onboarding-guide** — 環境構築、コードベース概要、開発フローを含む新規開発者向けオンボーディングガイドを生成

## コマンド (3)

- `/dev-documentation:docs` — ドキュメント作成の一連ワークフローを実行（README 生成、API ドキュメント、技術仕様書）
- `/dev-documentation:readme` — プロジェクト概要、インストール、使い方、貢献方法を含む README.md を生成または更新
- `/dev-documentation:changelog` — Git 履歴、コミット、または提供リリース情報から CHANGELOG.md を生成
