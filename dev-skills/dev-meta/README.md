# dev-meta

スキルエコシステムの管理と拡張のためのメタスキル集です。現在のスキルセットでは対応できない領域を検出し、調査・分析を行い、必要に応じて新しいスキルを自動生成します。

## スキル (3)

| スキル | 説明 |
|--------|------|
| [skill-gap-analysis](./skills/skill-gap-analysis/SKILL.md) | スキルギャップの検出と分析 |
| [skill-research](./skills/skill-research/SKILL.md) | 不足領域の調査と情報収集 |
| [skill-generator](./skills/skill-generator/SKILL.md) | 新しいスキルの自動生成 |

## コマンド (2)

| コマンド | 説明 |
|----------|------|
| `/skill-gap` | ギャップ分析 → 調査 → スキル生成の一連のワークフロー |
| `/new-skill` | 新しいスキルを直接生成 |

## 使用例

### スキルギャップの検出

```
/skill-gap "GraphQL APIの設計とベストプラクティス"
```

AIが以下を実行します：
1. 既存スキルを分析し、対応可能かを判定
2. 不足している場合、Web検索等で調査を実施
3. 調査結果を基に新スキルのドラフトを生成
4. 生成したスキルをレビュー用に提示

### 新スキルの直接生成

```
/new-skill "GraphQL API design" --category architecture --tags graphql,api,schema
```

## ワークフロー

```
┌─────────────────┐
│  ユーザー要求   │
└────────┬────────┘
         ▼
┌─────────────────┐
│ skill-gap-      │ ← 既存スキルとのマッチング
│ analysis        │   カバレッジ判定
└────────┬────────┘
         ▼
    ┌────┴────┐
    │カバー？ │
    └────┬────┘
    No   │   Yes
    ▼    └────→ 既存スキルを使用
┌─────────────────┐
│ skill-research  │ ← Web検索、ドキュメント調査
└────────┬────────┘   ベストプラクティス収集
         ▼
┌─────────────────┐
│ skill-generator │ ← SKILL.md フォーマットで生成
└────────┬────────┘   プラグイン構造に準拠
         ▼
┌─────────────────┐
│  レビュー＆保存  │
└─────────────────┘
```

## インストール

```bash
claude plugins:install ./dev-skills/dev-meta
```
