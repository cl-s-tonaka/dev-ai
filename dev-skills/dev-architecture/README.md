# dev-architecture

システム設計書、Architecture Decision Record（ADR）、設計パターン、API 設計、データベーススキーマ、マイクロサービス分割、スケーラビリティ分析、C4 モデル図に対応するソフトウェアアーキテクチャスキルを提供します。

## スキル (10)

- **system-design** — 要件、アーキテクチャ、コンポーネント、データフロー、デプロイ戦略を網羅した包括的なシステム設計書を作成
- **architecture-decision-record** — 背景、意思決定、影響、検討した代替案を記録した ADR を作成
- **design-patterns** — 要件を分析し、適切な設計パターン（GoF、エンタープライズ、アーキテクチャ）を実装ガイダンス付きで提案
- **api-design** — エンドポイント仕様、リクエスト/レスポンススキーマ、認証、バージョニング、ドキュメントを含む REST/GraphQL API を設計
- **database-schema** — エンティティ関係、正規化分析、インデックス戦略、移行計画を含む DB スキーマを設計
- **microservices-design** — ドメイン駆動設計原則でモノリスをマイクロサービスへ分割し、サービス境界と通信パターンを定義
- **scalability-analysis** — スケーラビリティのボトルネックを分析し、水平/垂直スケーリング戦略を提案
- **trade-off-analysis** — 重み付き評価基準を用いて技術選定を評価し、利点・欠点・リスクを整理
- **c4-diagram** — C4 モデル図（Context、Container、Component、Code）を PlantUML または Mermaid で生成
- **event-storming** — イベントストーミングを進行し、ドメインイベント、コマンド、集約、境界づけられたコンテキストを抽出

## コマンド (4)

- `/dev-architecture:design` — システム設計のフルワークフローを実行（要件整理、構成設計、意思決定記録、図生成）
- `/dev-architecture:adr` — 背景、判断根拠、影響、代替案を含む ADR を作成
- `/dev-architecture:api` — API を設計（エンドポイント、スキーマ、認証、エラーハンドリング、OpenAPI 生成）
- `/dev-architecture:scale` — システムの拡張性を分析（ボトルネック特定、キャパシティモデル化、改善ロードマップ作成）
