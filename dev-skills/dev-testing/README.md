# dev-testing

テスト戦略、単体/統合/E2E テスト設計、TDD ガイダンス、テストカバレッジ分析、モック戦略、テストデータ生成のためのスキルを提供します。

## スキル (8)

- **test-strategy** — テストピラミッドまたはテストトロフィーの考え方を使い、レイヤー別の配分を定義した包括的なテスト戦略を策定
- **unit-test-design** — AAA（Arrange-Act-Assert）や Given-When-Then パターンを用い、適切な分離とアサーションを備えた効果的な単体テストを設計
- **integration-test-design** — コンポーネント連携、API 契約、DB 操作、外部サービス依存を対象に統合テストを設計
- **e2e-test-design** — 重要ユーザージャーニー、クロスブラウザ検証、本番相当シナリオを含む E2E テストを設計
- **test-coverage-analysis** — テストカバレッジ指標を分析し、ギャップ特定と実行可能な改善計画を作成
- **tdd-guide** — Red-Green-Refactor ワークフロー、テストファースト、段階的設計で TDD を実践
- **mock-strategy** — テスト分離のためのモック/スタブ戦略を設計し、シナリオに応じたテストダブルを選定
- **test-data-generation** — フィクスチャ、ファクトリ、エッジケース、境界条件を含む現実的なテストデータを生成

## コマンド (3)

- `/dev-testing:test-plan` — 包括的なテスト計画を作成（戦略策定、テストケース設計、優先度付け）
- `/dev-testing:tdd` — TDD ワークフローを実行（失敗するテスト作成 → 最小実装 → 緑を維持してリファクタ）
- `/dev-testing:coverage` — カバレッジを分析し、ギャップ特定と優先度付き改善計画を作成
