# dev-debugging

根本原因分析、ログ分析、スタックトレース分析、性能プロファイリング、メモリリーク検出、インシデントのポストモーテムに対応するデバッグ/トラブルシューティングスキルを提供します。

## スキル (6)

- **root-cause-analysis** — 5 Whys やフィッシュボーン（石川）図を使った構造的な根本原因分析を実施し、問題の真因を特定
- **log-analysis** — アプリケーションログを分析し、デバッグと監視に有用なパターン・異常・相関を検出
- **stack-trace-analysis** — スタックトレースを解析して例外発生源、呼び出し連鎖、修正候補を特定
- **performance-profiling** — CPU、メモリ、I/O、ネットワークのボトルネックを特定するために性能をプロファイリング
- **memory-leak-detection** — ヒープ分析とオブジェクトライフサイクルトラッキングでメモリリークを検出し、改善策を提示
- **incident-postmortem** — 非難しないポストモーテムを実施し、事象記録、根本原因特定、アクションアイテム作成を行う

## コマンド (3)

- `/dev-debugging:debug` — デバッグのフルワークフローを実行（再現、分析、修正、検証）
- `/dev-debugging:postmortem` — タイムライン再構成、根本原因分析、アクションアイテムを含む非難しないポストモーテムを実施
- `/dev-debugging:profile` — アプリケーション性能をプロファイリングし、最適化提案を生成
